Green Vancouver: Tree Species Visualization with Altair

📌 Project Overview

This project explores the distribution of urban tree species across Vancouver using interactive visualizations powered by Altair. With over 5,000 data points on public street trees, the analysis uncovers spatial and environmental patterns through rich, browser-ready visuals.

The goal was to support urban forestry decision-making by answering:

Where are specific species concentrated? Do certain neighborhoods have greater biodiversity? How does tree distribution vary across street sides?
